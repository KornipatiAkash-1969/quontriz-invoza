1. Executive Summary

Quontriz Invoza is a production-grade enterprise platform engineered to automate supermarket and retail procurement workflows. It replaces error-prone paper workflows with automated OCR extraction, category classification, human-in-the-loop side-by-side reconciliation, owner payment recording, and real-time inventory demand fulfillment.

4. Enterprise Security & Zero-Leak Architecture

🔒 Salted Bcrypt Hashing

All passwords stored in the database are hashed with 10 salt rounds ($2b$10$). Login strictly verifies hashes using bcrypt.compareSync with zero plaintext bypasses.

🛡️ Zero-Leak API Policy

Database queries across /users, /me, and /login explicitly omit password_hash and token secrets. The /demo-users endpoint discloses zero passwords.

⏰ Midnight Session Expiry

All JWT authentication tokens automatically expire at 12:00:00 AM midnight, enforcing fresh authentication for daily supermarket shifts.

🚫 Zero OTP Dependency

The fragile OTP system has been completely eliminated. Users authenticate directly via email and password without third-party gateway failures.
